# 데이터 분석·시각화

## 원칙
- **사용자가 준 실제 자료만** 분석한다. 빠진 값을 채워 넣거나, 응답을 만들거나, 원하는 결과가 나오도록 자료를 바꾸지 않는다.
- 원자료는 고치지 않는다. 정리한 사본(`06_분석/정리자료.csv`)을 따로 만들고, 정리 규칙(제외 기준 등)을 기록한다.
- 모든 분석은 `06_분석/분석.py` 하나에 남겨 다시 돌리면 같은 결과가 나오게 한다.
- 개인정보(이름·학번 등)는 결과물에 넣지 않는다. 필요하면 번호로 바꾼다.

## 절차
1. **자료 살피기**: 행·열 수, 변수 설명, 빠진 값, 이상한 값, 척도(명목·서열·등간). 결과를 표로 보여 주고 변수의 뜻을 확인받는다.
2. **분석 고르기**: 연구문제마다 분석 방법을 제안하고 이유를 댄다.
   - 같은 집단 전·후: 대응표본 t검정(정규성 충족) / Wilcoxon 부호순위(소표본·비정규)
   - 두 집단: 독립표본 t검정 / Mann-Whitney U · 세 집단 이상: 일원분산분석(+사후검정) / Kruskal-Wallis
   - 범주 관계: 카이제곱(기대빈도 5 미만 많으면 Fisher) · 관계: Pearson / Spearman
   - 척도 신뢰도: Cronbach α · 내용타당도: I-CVI, S-CVI/Ave
   - 가정 확인: Shapiro-Wilk, Levene. 표본이 작으면(대략 30 미만) 비모수도 함께 본다.
3. **분석 실행**: pandas·scipy·statsmodels. 효과크기(Cohen's d, r, η², Cramér's V)를 함께 낸다.
4. **결과표**: `06_분석/결과표.md`(논문에 붙일 표, `<표 Ⅳ-1>` 형식)와 `.xlsx`. 숫자 표기는 thesis-writing-ko의 통계 표기를 따른다.
5. **해석문 초안**: 수치를 그대로 옮기고, 자료가 보여 준 만큼만 해석한다(인과·효과 단정 금지).
