# 0단계: 아이디어 브레인스토밍

결과 폴더: `연구/_아이디어탐색_<분야>/` (고른 아이디어는 `연구/<주제>/00_아이디어.md`로 넘긴다)

## 원칙
- 트렌드는 **숫자와 실제 논문**으로 보여 준다(baro-scholar). 짐작한 트렌드를 사실처럼 쓰지 않는다.
- 아이디어는 많이 내되, **교사·연구자가 실제로 할 수 있는지**를 함께 본다. AI가 낸 아이디어는 새롭게 보여도 실행이 어려운 경우가 많다(Si, Yang, & Hashimoto, 2025, "Can LLMs Generate Novel Research Ideas?"의 대규모 비교 연구). 그래서 실행 가능성으로 거르고, 고르는 건 사용자가 한다.
- 질문은 한 번에 3개까지만 한다. 대화하며 다듬는 단계라 산출물을 서둘러 만들지 않는다.

## 1. 관심 묻기 → `관심.md`
모르는 것만 묻는다: 공부하는 분야(예: 교육공학), 끌리는 키워드·현상(여러 개 가능), 대상(학교급·학년), 연구 여건(접근 가능한 학생·기간·기기), 피하고 싶은 것(예: 실험 설계, 대규모 설문), 원하는 결과물(학위·학술지). 키워드는 한국어·영어 동의어로 펼쳐 보여 주고 확인받는다.

## 2. 트렌드 지도 → `트렌드지도.md` + 그래프
키워드마다(최대 5개):
- `openalex_trend`(정확한 구문은 큰따옴표): 연도별 논문 수(전체 / 한국 저자). 최근 3년 증가율을 계산한다.
- `kci_trend`(KCI 키가 있으면): 국내 연도별 수. 없으면 `openalex_search`에 한국어 검색어를 넣어 국내 연구가 있는지만 본다.
- `openalex_topics`: 분야 전체 검색어(예: `"educational technology" elementary`)로 최근(2024~)과 이전(약 5년 전)을 비교해 **뜨는 주제**와 **가장 큰 주제**를 뽑는다.
- `openalex_search`(sort: `cited_by_count:desc`로 고전, `publication_year:desc`로 최신): 핵심 논문 10~20편.
- 그래프: data-analysis 스킬의 `kplot`으로 키워드별 연도 추이 선그래프(전체 vs 한국) 1장을 `트렌드_추이.png`로 저장하고 Read로 확인한다.
- 표로 정리: 키워드 | 국외 최근 3년 | 증가율 | 한국 저자 | 국내(KCI) | 해석 한 줄. 마지막 해(올해)는 진행 중이라 해석에서 빼거나 따로 표시한다.

## 3. 연구 흐름 사슬 → `연구흐름.md`
주요 주제 2~3개마다 대표 논문을 **시간순으로 4~6편** 잇는다(Chain of Ideas 방식). 각 고리: 저자(연도) — 무엇을 밝혔나 — 남긴 질문. 마지막에 "지금 어디까지 왔고, 다음 고리로 자연스러운 질문은 무엇인가"를 쓴다. 모든 논문은 `verify_reference`로 확인한다.

## 4. 빈틈 찾기 → `빈틈.md`
네 가지 틀로 찾는다. 빈틈마다 근거(어떤 논문들이 무엇을 안 했는지)를 단다.
| 종류 | 질문 |
|---|---|
| 대상·맥락 | 해외·중고등·대학에서는 했는데 **한국 초등**(또는 사용자의 대상)에서는 없는가 |
| 방법 | 설문만 있고 관찰·로그·실험·개발연구는 없는가, 횡단만 있고 종단은 없는가 |
| 이론 | 이론끼리 충돌하거나, 현상은 보고됐지만 설명(기제)이 없는가 |
| 분야 간 | 다른 분야(인지심리·HCI·의학교육)의 방법·도구를 옮겨 오면 풀리는가 |
국내에 같은 연구가 이미 있는지 `kci_search`(또는 `openalex_search` 한국어)로 꼭 확인한다.

## 5. 아이디어 후보 → `아이디어후보.md`
빈틈에서 **5~10개**를 만든다. 다양하게(대상·방법·이론을 섞어서) 만든 뒤 **비슷한 것은 합친다**. 각 후보:
```
### 후보 n. <한 줄 제목>
- 연구 질문:
- 채우는 빈틈: (4단계 근거 연결)
- 대상·규모·기간:
- 대략적 방법: (설계, 자료, 분석)
- 근거 논문 2~3편: (확인됨)
- 새로움 1~5 / 실행 가능성 1~5 / 관심 부합 1~5  — 각 한 줄 이유
- 가장 강한 반론 한 줄:
```
실행 가능성 2점 이하는 "조건이 바뀌면 가능"으로 따로 모은다.

## 6. 함께 고르기
점수표를 보여 주고 AskUserQuestion으로 1~2개를 고르게 한다(섞기·고치기도 가능). 고르면:
- `연구/<주제>/00_아이디어.md`를 만들어 후보 내용, 근거 논문, 트렌드 숫자를 옮기고
- start 스킬 1단계(아이디어 다듬기)로 이어 간다. 이미 확인한 문헌은 `01_문헌/문헌목록.md`로 넘겨 다시 찾지 않는다.

마음에 드는 게 없으면 무엇이 아쉬운지 묻고 2~5단계를 다른 키워드로 다시 돈다(최대 2번).
