# 문체 학습

## 원칙
- **사용자가 준 자료만** 쓴다. 컴퓨터 안을 마음대로 뒤지지 않는다. 대화 기록도 사용자가 위치나 파일을 알려 주거나 허락했을 때만 읽는다.
- 결과는 이 컴퓨터에만 저장한다(작업 폴더의 `문체프로필.md`, 그리고 원하면 `~/.baro-nonmun/style/<이름>.md`로 다른 연구에서도 재사용).
- 남의 글(공저자·지도교수·AI가 쓴 초안)이 섞여 있으면 어떤 파일이 본인이 직접 쓰거나 고친 글인지 묻는다. AI 초안은 문체 근거에서 뺀다.

## 1. 자료 받기
AskUserQuestion으로 묻는다: 본인이 쓴 논문·보고서 파일(가장 좋음), 고친 원고(수정 전·후가 있으면 더 좋음), 논문 작업 대화 기록(Claude Code 대화는 `~/.claude/projects/<폴더>/*.jsonl`, 다른 도구는 내보낸 텍스트).

## 2. 수치 분석
```bash
python "${CLAUDE_PLUGIN_ROOT}/skills/style-learning/scripts/style_stats.py" 파일1 파일2 … -o "연구/<주제>/문체_수치.json"
```
- 문서: hwpx·md·txt는 직접 읽고, docx·pdf·pptx는 markitdown, hwp는 thesis-format의 `convert`(Windows+한글)로 hwpx로 바꾼 뒤 넣는다.
- 대화 기록(.jsonl)을 넣으면 사용자 메시지 중 **글을 고치라고 한 말**(예: "~말고", "~로 바꿔", "~하지 마", "어색해")을 뽑아 `corrections`에 넣는다.

## 3. 프로필 쓰기 → `문체프로필.md`
수치와 실제 문장을 함께 보고 다음을 쓴다. 각 규칙에 근거(수치나 예문)를 붙인다.
```
# 문체 프로필: <이름> (자료: 파일 n개, 문장 n개, 기준일)
## 문장 끝맺음        예: '-하였다'(62%) > '-했다'(5%) → '-하였다'로 통일
## 문장 길이·리듬      평균 n자, 긴 문장은 쉼표로 …
## 자주 쓰는 연결어    그러나 > 따라서 > 또한 …, 문단 첫머리 습관
## 연구자 지칭        '연구자' / '본 연구'
## 인용 방식          (저자, 연도) 위치, 직접 인용 비율
## 용어·표기 습관      영어 병기, 숫자·단위, 따옴표
## 대화에서 고친 규칙  "○○ 말고 △△" → 규칙으로 (대화 기록이 있을 때)
## 피하는 표현        사용자가 싫어한 표현
## 예문 5개           사용자 글에서 그대로 가져온 대표 문장
```
## 4. 확인과 적용
프로필 요약을 보여 주고 고칠 곳을 묻는다. 확정 후 집필할 때는 thesis-writing-ko보다 프로필을 우선하되, 학교 지침이 가장 우선이다. 쓴 글을 프로필과 대조해 어긋난 곳을 고친다.
