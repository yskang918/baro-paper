# 할지 말지 판단 보고서

입력: `00_아이디어.md`, `01_문헌/문헌목록.md`·`문헌종합.md`, `02_연구설계.md`. 출력: `03_판단보고서.md`.

## 판단 기준 (각 1~5점, 점수마다 근거를 문헌·사실로)

| 기준 | 보는 것 |
|---|---|
| 1. 새로움 | 가장 비슷한 연구 3~5편과 무엇이 다른가(대상·맥락·방법·변인). 같은 연구가 이미 있으면 1~2점 |
| 2. 필요성 | 현장 문제·정책·이론적 공백의 근거가 확인된 자료로 있는가 |
| 3. 연구문제의 명확성 | 자료로 답할 수 있는 형태인가, 범위가 알맞은가 |
| 4. 실행 가능성 | 대상 접근(연구자 역할), 기간, 인원, 도구, 비용, 수업 운영과 충돌 |
| 5. 측정·분석 타당성 | 연구문제와 자료·도구·분석이 이어지는가, 표본 크기, 검증된 도구가 있는가 |
| 6. 윤리·위험 | 아동 대상 IRB·보호자 동의, 불이익·부담, 개인정보, 연구자가 담임일 때의 이해충돌 |
| 7. 기여 | 현장(교사·학생)과 학문에 남는 것 |
| 8. 연구자 적합성 | 연구자의 관심·경험·마감과 맞는가 |

## 판정 규칙

- **진행**: 평균 3.5 이상이고 1·4·6번이 모두 3점 이상
- **조건부 진행**: 평균 3.0 이상이지만 고칠 점이 있음 → 고칠 점을 구체적으로
- **다시 설계**: 1·4·6번 중 하나라도 2점 이하
- **보류**: 같은 연구가 이미 있거나, 기간·접근이 현실적으로 불가능

점수는 후하게 주지 않는다. 근거가 없는 칸은 "근거 부족"이라 쓰고 점수를 낮춘다.

## 보고서 구성

```
# 판단 보고서: <주제>
결론: 진행 / 조건부 진행 / 다시 설계 / 보류  (한 문장 이유)

## 점수표
| 기준 | 점수 | 근거(출처) |

## 가장 비슷한 연구와 차이
| 연구 | 대상·방법 | 우리와 다른 점 |

## 가장 강한 반론 3가지
(심사위원이 할 법한 비판. 일부러 반대 입장에서 쓴다)

## 살릴 방법 / 고칠 점
(반론마다 바꾸면 되는 설계)

## 연구를 하면 드는 것
기간·인원·준비물·승인 절차·예상 일정

## 확인하지 못한 것
```

## 주의

- 문헌은 `문헌목록.md`에서 확인된 것만 근거로 쓴다. 새로 인용하면 `verify_reference`로 확인한다.
- 결론은 사용자가 정한다. 보고서를 보여 준 뒤 진행 여부를 묻는다.
